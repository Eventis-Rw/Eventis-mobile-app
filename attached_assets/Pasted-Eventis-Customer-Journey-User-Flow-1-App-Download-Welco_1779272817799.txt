Eventis – Customer Journey (User Flow)
1. App Download & Welcome
The customer downloads the Eventis mobile application from the app store.
Upon opening the app for the first time, the customer will see:
* Welcome screen
* Terms & Policies confirmation
* Registration options:
    * Username
    * Phone number or Email address
The customer can continue with a basic registration without full verification.



2. Explore Events Immediately
Right after downloading the app, the customer can immediately:
* Browse nearby events based on location/proximity
* See banners and promoted events
* Search events by:
    * Category
    * Distance
    * Interest
    * Date
    * Trending events
No KYC is required at this stage.



3. Interest in an Event
When the customer selects an event, they can view:
* Event details
* Venue/location
* Date & time
* Ticket price
* Organizer information
* Number of attendees
* Event images/videos



4. Booking & KYC Verification
When the customer decides to book or attend an event:
For Paid Events
The system will require a simple KYC verification before payment and booking.
Required verification:
* Phone number verification using OTP (One-Time Password)
OR
* Email verification using OTP/code confirmation
After successful verification, the customer can:
* Book tickets
* Make payments
* Receive digital tickets
* Access booking history



For Free Events
If the event is free:
* No phone verification is required for booking
* The customer can reserve attendance instantly
This reduces friction and increases participation for free community events.



5. Payment Process (Paid Events)
For paid events, the customer proceeds to payment using:
* Credit/Debit Card
* Mobile Money
* Apple Pay / Google Pay
* Wallet balance (if available)
After successful payment:
* Ticket confirmation is generated
* QR code or digital pass is issued
* Confirmation notification is sent



6. In-App Chat & Communication
To use the in-app chat system, the customer must complete phone verification.
Verified users can:
* Chat with event organizers
* Communicate with attendees
* Receive event updates
* Join event discussion groups
This helps reduce spam and fake accounts.



7. Event Attendance
On the event day, the customer can:
* Present QR code/ticket
* Check in digitally
* Receive live event notifications
* Access event schedules/maps



8. Post-Event Experience
After attending the event, the customer can:
* Rate and review the event
* Share photos/videos
* Save favorite organizers
* Receive personalized recommendations
* Get notifications for similar nearby events



Simplified Customer Flow
1. Download App
2. Accept Policies
3. Register (Username + Phone/Email)
4. Browse Nearby Events Immediately
5. Select Event
6. If Paid Event → OTP Verification + Payment
7. If Free Event → Direct Booking
8. Access Chat → Phone Verification Required
9. Attend Event
10. Review & Discover More Events
11.

Eventis – Business & Event Poster Journey
1. Registration as Event Poster
To post events on Eventis, the user must register either as:
* Business Account OR
* Individual Event Poster
During registration, the poster will provide:
* Business name or individual name
* Phone number
* Email address
* Password
* Event categories/types
* Business location
* Social media links (optional)
* Website link (required for paid events)



2. Account Type Selection
Business Account
For companies, brands, clubs, organizations, venues, or professional event organizers.
Individual Poster Account
For freelancers, community organizers, artists, influencers, or individuals hosting events.



3. Event Profile Setup
After registration, the poster creates their event profile by adding:
* Event title
* Event category
* Event description
* Event location
* Event date & time
* Ticket type
* Event capacity
* Contact information
* Event images/videos
* Promotional banners
Supported event categories may include:
* Music
* Sports
* Business
* Community
* Education
* Nightlife
* Festivals
* Conferences
* Food & Culture
* Religious
* Entertainment
* Fashion
* Technology



4. Paid Event Verification & Compliance
For Paid Events
If the organizer wants to charge customers for tickets, additional verification is required.
The organizer must provide:
* Business registration documents
* Legal business name
* Website URL
* Payment processing website
* Tax/business identification documents (if applicable)



Payment Processing Policy
Eventis does not process payments directly for paid events.
Instead:
* Customers are redirected to the organizer’s official website for payment
* The organizer manages:
    * Payments
    * Refunds
    * Ticket processing
    * Financial compliance
This reduces platform liability and allows businesses to maintain control of their transactions.



5. Event Upload & Publishing
Once approved, the organizer can upload:
* Events
* Product banners
* Promotional banners
* Sponsored advertisements
* Event posters
* Video promotions
* Brand visuals
The organizer can:
* Edit events
* Pause events
* Delete events
* Boost visibility
* Track engagement analytics



6. Home Page Promotion System
Sponsored Placement
Businesses that want premium visibility on the home page must pay for promotional placement.
Paid promotion options may include:
* Home page banners
* Featured event section
* Category highlights
* Nearby promoted events
* Trending events
* Sponsored ads
Promotion pricing can vary based on:
* Duration
* Banner size
* Audience reach
* Event category
* Geographic targeting



7. Customer Discovery
After publishing:
* Events become discoverable based on:
    * User proximity
    * Interests
    * Categories
    * Trending activity
    * Sponsored ranking
Users can:
* View event details
* Save events
* Share events
* Book attendance
* Visit the organizer’s payment website



8. Communication & Engagement
Verified organizers can:
* Chat with attendees
* Send announcements
* Share updates
* Respond to questions
* Promote future events
Phone verification is required for organizer communication features.



9. Analytics & Performance Dashboard
Event posters can access:
* Event views
* Click-through rates
* Attendance metrics
* Promotion performance
* Audience engagement
* Banner analytics
This helps organizers optimize future events and promotions.



Simplified Business Journey
1. Download Eventis
2. Register as Business or Individual Poster
3. Add Business/Profile Information
4. Choose Event Categories
5. Upload Event Details & Visuals
6. For Paid Events → Submit Business Documents + Website
7. Get Verification Approval
8. Publish Events & Promotions
9. Pay for Featured Home Page Placement (Optional)
10. Customers Discover & Attend Events
11. Track Analytics & Engagement
